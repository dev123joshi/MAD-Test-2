# ✈️ TravelPass – Android Application

## 📱 Overview

**TravelPass** is an Android application developed using **Android Studio** and **Kotlin**. The application provides a simple user interface for users to log in and manage their travel profile and preferences.

The project demonstrates important Android development concepts such as **Activities, Intents, XML layouts, RadioButtons, CheckBoxes, Buttons, and Menu options**.

---

## ✨ Features

### 🔐 1. User Login
- Username input
- Password input
- Remember Me checkbox
- Login button

### 👤 2. User Profile Management
Users can manage and save their profile information and travel preferences.

### 🌡️ 3. Preference Selection
The application uses **RadioButtons** for selecting preferences such as:

- Celsius (°C)
- Fahrenheit (°F)

### 🔔 4. Travel Alerts
Users can enable or disable:

- Receive Travel Alerts

using a **CheckBox**.

### 💾 5. Save Profile
Users can save their selected profile settings using the **Save Profile** button.

### 📋 6. Menu Integration
The application includes a menu for additional navigation and options.

## 🚀 How to Run the Project

1. Clone this repository.

```bash
git clone <repository-url>
```

2. Open **Android Studio**.

3. Select **Open** and choose the **TravelPass** project folder.

4. Wait for **Gradle Sync** to complete.

5. Connect an Android device or start an Android Emulator.

6. Click the **Run ▶** button.
